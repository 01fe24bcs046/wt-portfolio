📌 About This Project

WorkDist / TaskBridge is an Employee Work Distribution System developed as part of the Software Engineering course at KLE Technological University, Academic Year 2025–26.

The system provides a centralized platform for task assignment, employee management, progress tracking, notifications, audit logs, and analytics — improving productivity, accountability, and workflow efficiency across organizations.

Built with the MERN stack (MongoDB, Express, React, Node.js), secured with JWT authentication and Google OAuth 2.0, and deployed on Vercel.

⚠ Problem

Problem Statement

Organizations managing distributed teams lack a centralized, role-aware system for task assignment, tracking, and accountability.

📖 Background
Organizations often face difficulties in managing tasks, tracking employee progress, monitoring deadlines, and maintaining proper communication between managers and employees. Existing manual methods lead to delayed work, poor coordination, lack of transparency, and inefficient workload management.

Root Causes

⏰ Missed Deadlines
No automated deadline tracking or overdue alerts for managers. Tasks slip through with no visibility into approaching or passed deadlines.
🕵️ Zero Visibility
Managers cannot see real-time task status or employee workload distribution. No unified dashboard to monitor team progress.
📋 No Accountability
No audit trail — task changes, submissions and flags go completely unrecorded. No way to trace actions back to specific users.
💬 Communication Gaps
Feedback and revision cycles are lost across fragmented email threads. No centralized comment or notification system.
🎯 Objective

Build a role-based web application (Super Admin → Manager → Employee) that automates task distribution, tracking, review, and feedback with full audit logging.

📋 Requirements

System Requirements

Functional and non-functional requirements defined for the WorkDist / TaskBridge system.

✅ Functional Requirements — FR-01 to FR-20
🔐 Authentication & Access (FR-01–04)
  • FR-01: Login with email & password
  • FR-02: Google OAuth 2.0 login
  • FR-03: Force password change on first login
  • FR-04: Secure logout
📋 Task Management (FR-05–11)
  • FR-05: Create, edit, delete tasks
  • FR-06: Assign with deadline & priority
  • FR-07: Attach files to tasks
  • FR-08: View & accept assigned tasks
  • FR-09: Submit deliverables
  • FR-10: Request deadline extensions
  • FR-11: Review, approve or request revision
👥 User & Role Management (FR-12–15)
  • FR-12: Super Admin creates & manages companies
  • FR-13: Super Admin manages manager accounts
  • FR-14: Managers manage employee accounts
  • FR-15: Role-based access control
🔔 Notifications, Audit & Reporting (FR-16–20)
  • FR-16: Notifications for tasks, comments, submissions
  • FR-17: View unread notifications
  • FR-18: Maintain audit logs for all activities
  • FR-19: Dashboards for task status & team workload
  • FR-20: Generate performance reports
🛡 Non-Functional Requirements — NFR-01 to NFR-12
⚡ NFR-01 Performance
Pages load & actions process within 2 seconds under normal network conditions.
🔐 NFR-02 Security
Passwords stored as salted hashes; all data transmitted over HTTPS only.
🤝 NFR-03 User Friendly
Interface operable by managers and employees without special training.
✅ NFR-04 Reliability
Functions correctly without unexpected failures during normal operations.
🌐 NFR-05 Availability
Available whenever managers and employees need to access tasks and data.
🔒 NFR-06 Privacy
No personal information disclosed to unauthorized parties.
🔧 NFR-07 Maintainability
Designed to be easily updated, tested, and corrected with minimal effort.
📈 NFR-08 Scalability
Supports growth in users, tasks, and data without major system changes.
📱 NFR-09 Portability
Accessible through modern web browsers on different devices without compatibility issues.
🗄 NFR-10 Data Integrity
Ensures data accuracy during creation, updates, and status changes.
📜 NFR-11 Auditability
Maintains logs of all important activities for monitoring and audit purposes.
♻ NFR-12 Recoverability
Allows data recovery in case of unexpected errors or failures without data loss.
